# Sparse Group Pliable Lasso (SGPL)

An R implementation of the **Sparse Group Pliable Lasso (SGPL)** for Gaussian, binomial, and Cox proportional hazards models using block-wise coordinate descent with nested proximal updates.

## Installation

Install the development version directly from GitHub.

```r
# install.packages("remotes")

remotes::install_github("edelweiss611428/SGPL")
```

Then load the package

```r
library(SGPL)
```
